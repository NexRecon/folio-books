# Folio — curated digital bookstore

A demo storefront built with Vite, React, TypeScript, Tailwind CSS v4, Framer Motion and Lucide.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + production build
npm run preview  # serve the build
```

## Features

- Hero with a 3D-tilt featured book (disabled for touch and reduced motion)
- Catalog with category filter and simulated live search
- Quick-view drawer (summary, author bio, rating) and cart drawer (quantities, live total, saved in localStorage)
- Light/dark theme, glass accents, accessible drawers (focus trap, Esc, focus restore)

All titles and authors are fictional; checkout and newsletter are demos and send nothing.
